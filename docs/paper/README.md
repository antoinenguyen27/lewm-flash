# Report, presentation and solution pack

- `report.pdf` / `report.docx`: *Planning at the Speed of Control: Profiling and fusing world-model robot planning into
  a single GPU kernel* (project report).
- `presentation.pptx` / `presentation.pdf`: 14-slide deck with speaker notes.
- `solution_pack.zip`: datasets, the solution program and the kernel sources, for submission (built by
  `solution_pack/make_archive.sh`; the unpacked pack is `solution_pack/` at the repository root).

Report sources are in `src/`: chapter markdown in `sections/`, diagrams from `make_diagrams.py`, data figures copied
from `solution_pack/outputs/figs` (generated by `python solution_pack/lewm_flash.py`), the annotated bibliography in
`litreview.md`, and the deck in `deck/make_deck.js`.

```bash
python solution_pack/lewm_flash.py && cp solution_pack/outputs/figs/*.png docs/paper/src/figs/
python docs/paper/src/make_diagrams.py
NODE_PATH=<node_modules with docx@9> PY=<python with pypdf> docs/paper/src/build_all.sh   # needs LibreOffice
NODE_PATH=<node_modules with pptxgenjs> node docs/paper/src/deck/make_deck.js
```
